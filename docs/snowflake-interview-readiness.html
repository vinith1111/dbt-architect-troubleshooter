Snowflake Interview Readiness Lab

Practice the way a real Snowflake Data Engineer is evaluated: diagnose before changing things, prove the root cause with evidence, choose a safe fix, and explain how you would validate it. This is practical interview preparation, not a job guarantee.

Use this answer structure: clarify impact and scope → state a hypothesis → inspect evidence → apply the smallest safe fix → validate correctness and performance → add prevention/monitoring. Don’t jump straight to “increase warehouse size.”

Hands-on SQL drills

Run these in a Snowflake practice schema. Use synthetic data, not production customer data. Adapt object names and privileges to your environment.

1. Find duplicate business keys

SELECT order_id, COUNT(*) AS row_count
FROM RAW.ORDERS
GROUP BY order_id
HAVING COUNT(*) > 1
ORDER BY row_count DESC;

Follow-up: determine whether duplicates are legitimate versions, repeated file delivery, or a broken join before deleting anything.

2. Compare source and target by business date

SELECT 'SOURCE' AS layer, order_date, COUNT(*) AS row_count,
       COUNT(DISTINCT order_id) AS distinct_orders,
       SUM(amount) AS total_amount
FROM STAGE.ORDERS
GROUP BY order_date
UNION ALL
SELECT 'TARGET', order_date, COUNT(*),
       COUNT(DISTINCT order_id), SUM(amount)
FROM MART.ORDERS
GROUP BY order_date
ORDER BY order_date, layer;

Follow-up: align filters, time zone, late-arriving data, currency/rounding, deletes, and the comparison window before declaring a defect.

3. Inspect query history for a slow query

SELECT query_id, start_time, total_elapsed_time,
       execution_status, warehouse_name, bytes_scanned,
       rows_produced, query_text
FROM SNOWFLAKE.ACCOUNT_USAGE.QUERY_HISTORY
WHERE start_time >= DATEADD(day, -1, CURRENT_TIMESTAMP())
  AND query_text ILIKE '%ORDERS%'
ORDER BY start_time DESC
LIMIT 50;

Access and latency depend on account privileges and Account Usage view freshness. For immediate investigation, consider the relevant Information Schema table functions and Query Profile.
