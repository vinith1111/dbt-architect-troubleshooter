When the exact answer is not listed

  1. Copy the full error, not only the last line.
  2. Record the command you ran, model name, adapter, and whether it fails locally or in CI.
  3. Check the first meaningful error in the log. Later errors may be consequences.
  4. Use Check a dbt problem for guided diagnostics or open the relevant dbt lesson.
  5. Do not apply a production fix until you have reproduced the issue and validated the result.

If a result says “more evidence needed,” that is intentional. A safe tool should tell you what it cannot know rather than guess.
